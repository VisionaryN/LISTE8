# Demain

Mini app perso : tu dictes une note, Claude la range.
- **Tâches** → dans l'agenda (demain par défaut, ou le jour/l'heure que tu dis)
- **Idées long terme** → dans l'onglet Idées

Blanc, minimaliste, Poppins. Tout reste sur le téléphone (localStorage). La clé API Claude est saisie dans l'app (menu •••) et n'est jamais dans le code.

## Installer sur iPhone
1. GitHub → Settings → Pages → Source : *Deploy from a branch*, branche de ce projet, dossier `/docs`.
2. Ouvre l'URL Pages dans **Safari** → Partager → **Sur l'écran d'accueil**.
3. Ouvre l'app → ••• → colle ta clé API (platform.claude.com).

Dictée : bouton micro dans la feuille de saisie si le navigateur le permet ; sinon le micro du clavier iOS.
